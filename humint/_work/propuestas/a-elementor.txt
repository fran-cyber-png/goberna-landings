PROPUESTA A — «la lista se desplaza» (sección Plan de estudios)
=============================================================================

QUÉ HACE
  Al bajar la página, la sección de módulos se queda fija justo debajo del header
  (90 px en desktop, 80 px en laptop). Mientras el usuario sigue bajando, la lista
  del acordeón avanza en proporción al scroll, del módulo 01 al 10. Cuando llega al
  final, la sección se suelta y la página continúa normal. Al subir, pasa lo mismo
  al revés. La página hace scroll normal: no se intercepta la rueda.

SOLO DESKTOP (≥1367) Y LAPTOP (1025–1366)
  En tablet y mobile, y con «prefers-reduced-motion: reduce», no se fija nada.

QUÉ HAY QUE CREAR EN ELEMENTOR (no se toca el JSON en esta propuesta)
  1. Un contenedor NUEVO que envuelva la sección 7c39e8aa (Plan de estudios):
       - Contenedor nuevo: ancho completo (full), sin relleno ni margen.
       - Clase CSS: ak-plan-pin
       - ID de CSS (Avanzado → Atributos → ID de CSS): modulos
         (el enlace «MÓDULOS» del menú apunta a #modulos; el ID pasa del contenedor
         ak-plan al nuevo, así el enlace sigue llevando al inicio de la sección)
       - Dentro: la sección 7c39e8aa tal cual, con su clase ak-plan. Quitar de la
         sección el ID de CSS «modulos» si lo tiene.
  2. CSS: pegar el bloque CSS de abajo en Avanzado → CSS personalizado del
     contenedor ak-plan-pin. En ese bloque, «selector» es el propio contenedor.
  3. Widget HTML con el bloque JS de abajo, colocado DESPUÉS de ak-plan-pin
     (en la misma sección de la página). El script busca por clases, no por ID de
     Elementor, así que no depende de los ids generados.

CÓMO FUNCIONA (técnica)
  - ak-plan-pin es el contenedor exterior. Su alto se recalcula con JS:
        alto de la sección + recorrido de la lista (scrollHeight − clientHeight).
  - ak-plan (la sección) es position:sticky con top = alto del header. Se queda
    pegada mientras el contenedor exterior tiene scroll pendiente.
  - Cuando la sección está fijada, el script pone:
        list.scrollTop = progreso × recorrido,
    con progreso = (scrollY − inicio de la fijación) / recorrido, limitado a 0..1.
  - El alto visible de la lista: si la pantalla es baja, la lista se achica para que
    la sección completa quepa bajo el header (mínimo 240 px). En 1920×1080 no cambia.
  - Se recalcula con ResizeObserver (sección, lista y cada módulo, así que al abrir o
    cerrar uno cambia el recorrido) y en resize, con requestAnimationFrame.
  - Scroll pasivo en window (passive:true). No hay preventDefault en la rueda.

DECISIONES
  - La rueda sobre la lista NO la mueve: mientras la sección está fijada, la lista tiene
    overflow:hidden (clase is-on en ak-plan-pin). Así la rueda sobre ella hace scroll de
    la página, y la lista solo cambia con el progreso del scroll. Sin pelear con el
    script ni tocar la rueda.
    Limitación: el foco por teclado dentro de la lista puede desplazarla; en el siguiente
    scroll de página vuelve a la posición que marca el progreso.
  - Mobile/tablet y reduced-motion: el script no activa nada (is-on no se pone) y la lista
    queda con su CSS original.
  - Barra opcional de progreso (SHOW_PROGRESS = true): línea roja #DD0005 de 3 px en el
    borde inferior de la sección, que crece con el progreso. Desactivada por defecto.

LIMITACIONES
  - Pantallas bajas: si la sección no cabe bajo el header, la lista se achica (ver arriba).
    Esto cambia el alto visible de la lista en 1440×900 (760 → ~614 px) y en 1366×768
    (600 → ~512 px). En 1920×1080 no cambia.
  - Si ni así cabe (p. ej. 1025×700, donde la columna izquierda mide 733 px), la sección
    NO se fija: se queda como está ahora. Así nunca se oculta la parte de abajo.
  - Sin JS, la lista queda visible y con scroll propio (fallback seguro, sin pineado).
  - No se ha probado en Safari ni en Firefox; solo en Chromium (Playwright).

RECORRIDO EXTRA DE SCROLL QUE AÑADE (medido en la vista previa, con el módulo 01 abierto)
  1920×1080: 1180 px (lista 760 px visibles)
  1440×900:  1326 px (lista 614 px visibles; se achica para caber)
  1366×768:   890 px (lista 512 px visibles; se achica para caber)
  1025×700:   no se fija (la sección no cabe bajo el header)
  375 y tablet: no se fija (igual que ahora)

=== JS (widget HTML: pegar dentro de <script>…</script>) ==================================

(function () {
  'use strict';
  var SHOW_PROGRESS = false;              // true = barra roja de progreso (opcional)

  var wrap = document.querySelector('.ak-plan-pin');
  if (!wrap) return;
  var sec = wrap.querySelector('.ak-plan');
  var list = sec && sec.querySelector('.e-n-accordion');
  if (!sec || !list) return;
  var items = [].slice.call(list.querySelectorAll('details'));
  var mqDesk = window.matchMedia('(min-width: 1025px)');
  var mqReduce = window.matchMedia('(prefers-reduced-motion: reduce)');
  var on = false, fitting = false, ticking = false, bar = null;

  if (SHOW_PROGRESS) {
    bar = document.createElement('i');
    bar.className = 'ak-plan-prog';
    sec.appendChild(bar);
  }

  // Alto del header que deja libre la sección: lo lee del CSS (top de la sección fijada)
  function stickTop() { return parseFloat(getComputedStyle(sec).top) || 0; }
  function pageTop(el) { return el.getBoundingClientRect().top + window.pageYOffset; }

  // Recorrido de la lista (cuánto puede avanzar dentro de la sección)
  function travel() { return Math.max(0, list.scrollHeight - list.clientHeight); }

  // Alto de la lista (el de diseño, o el que quepa bajo el header) y alto de la wrap.
  // Si ni con la lista en su mínimo cabe la sección bajo el header (p. ej. la columna izquierda
  // es más alta que la pantalla), no se fija: la página se ve como ahora.
  function recalc() {
    if (!on || fitting) return;
    fitting = true;
    list.style.maxHeight = '';                                  // alto de diseño (CSS)
    var nat = parseFloat(getComputedStyle(list).maxHeight) || list.offsetHeight;
    var avail = window.innerHeight - stickTop() - (sec.offsetHeight - list.offsetHeight);
    list.style.maxHeight = Math.max(240, Math.min(nat, avail)) + 'px';
    if (sec.offsetHeight > window.innerHeight - stickTop()) {   // no cabe: sin fijar
      wrap.classList.remove('is-on');
      wrap.style.height = '';
      list.style.maxHeight = '';
      on = false;
      fitting = false;
      return;
    }
    wrap.style.height = (sec.offsetHeight + travel()) + 'px';   // sección + recorrido
    fitting = false;
    update();
  }

  // Progreso del scroll de la página -> scrollTop de la lista
  function update() {
    if (!on) return;
    var t = travel();
    var start = pageTop(wrap) - stickTop();                     // scroll en el que la sección se fija
    var p = t > 0 ? (window.pageYOffset - start) / t : 0;
    p = Math.min(1, Math.max(0, p));
    list.scrollTop = p * t;
    if (bar) bar.style.transform = 'scaleX(' + p + ')';
  }

  function onScroll() {
    if (ticking) return;
    ticking = true;
    requestAnimationFrame(function () { ticking = false; update(); });
  }

  function setOn(v) {
    if (v === on) return;
    on = v;
    if (on) {
      wrap.classList.add('is-on');
    } else {
      wrap.classList.remove('is-on');
      wrap.style.height = '';
      list.style.maxHeight = '';
      if (bar) bar.style.transform = 'scaleX(0)';
    }
  }

  function sync() {
    setOn(mqDesk.matches && !mqReduce.matches);
    recalc();
  }

  // Cambios de tamaño de la sección, de la lista y de cada módulo (abrir/cerrar)
  if ('ResizeObserver' in window) {
    var ro = new ResizeObserver(function () { recalc(); });
    ro.observe(sec); ro.observe(list);
    items.forEach(function (d) { ro.observe(d); });
  }
  window.addEventListener('scroll', onScroll, { passive: true });
  window.addEventListener('resize', sync, { passive: true });
  window.addEventListener('load', sync);
  if (mqDesk.addEventListener) { mqDesk.addEventListener('change', sync); mqReduce.addEventListener('change', sync); }
  sync();
})();
